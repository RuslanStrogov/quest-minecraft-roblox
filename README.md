# 🎂 КВЕСТ «МАЙНКРАФТ + ROBLOX» — День рождения двойняшек

Уличный квест для детей 4–8 лет. 6 этапов, 40 минут, реквизит за вечер своими руками.

**[📄 Скачать полную инструкцию](instructions.md) · [🖨️ Печатная версия PDF](instructions.pdf)**

## Превью

| Файл | Как выглядит |
|---|---|
| **Записки** | 5 карточек, коричневый фон, пиксельная зелёная рамка |
| **Алмазы** | 6 голубых кристаллов сложной огранки со звездой |
| **Клинок** | Меч на весь А4: голубое лезвие, 65 см |
| **Лава** | 12 оранжево-красных квадратов, подпись «НЕ НАСТУПАТЬ!» |
| **HP сердца** | 12 красных сердечек с бликом |
| **Пламя** | 2 языка пламени, прикрепить к мишуре |
| **Слеза моба** | 8 этикеток с голубой каплей |
| **Маска** | 2 листа: рога для каски + выкройка накидки |
| **Сундуки** | 4 наклейки с замками и полосами |
| **Крафт** | Сетка 3×3, верхний ряд — слоты для алмазов |
| **Карта** | Пергамент, 4 ресурса, портал, стикеры |
| **SCP/obby** | Серые SCP-таблички, зелёные obby, портал |
| **Этажи** | 5 зелёных табличек с цифрами 1–5 |
| **Обклейка** | Узор «под дерево», печатать 4+ листа |
