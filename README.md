# 🎂 КВЕСТ «МАЙНКРАФТ + ROBLOX» — День рождения двойняшек!

**Уличный квест своими руками за один вечер**
*Время проведения: ~40 минут | Возраст: 4–8 лет | Участников: 2–4*

---

## Что это?

Это сценарий для уличного квеста в стиле Minecraft и Roblox. Дети — «игроки», которые «спавнятся» во дворе. Им нужно пройти 6 этапов, собрать 4 ресурса и в финале победить Эндер-дракона (папу). Каждый этап — отдельный «биом» из Minecraft с наградой.

## Как сделать реквизит (пошагово)

### 🔷 Сундуки (4 шт.)
1. Обклей коробки коричневой бумагой
2. Сверху наклей распечатанную текстуру под дерево (`14-chest-wrap.svg`)
3. Приклей металлические полоски из фольги (2 поперёк коробки)
4. Нарисуй/приклей заклёпки — чёрные точки по краям
5. Наклей этикетку из `09-chest-labels.svg`
6. Внутрь положи записку или алмазы

### 💎 Алмазы (6 шт.)
1. Вырежи 6 фигур из распечатки `02-diamonds.svg`
2. Приложи к картону, обведи, вырежи
3. Покрась голубым акрилом с обеих сторон
4. Дай высохнуть (30 мин)

### ⚔️ Алмазный клинок
1. Распечатай `03-diamond-sword.svg` × 2
2. Вырежи оба, склей их спинками (для жёсткости)
3. Приложи к листу картона, обведи, вырежи
4. Обклей фольгой — как настоящее оружие из Minecraft

### 🔥 Пламя выносливости
1. Вырежи 2 пламени из распечатки `06-flame-endurance.svg`
2. Приклей к жёлтой мишуре или бумажному помпону

### ❤️ Сердечки HP (10 шт.)
1. Вырежи по контуру `05-hp-hearts.svg`
2. Приклей к картону для жёсткости (опционально)
3. Раздай по 5 каждому игроку перед финалом

### 💧 Слеза моба
1. Вырежи этикетку `07-mob-tear.svg`
2. Наклей на синюю бусину или камешек

### 🐉 Маска дракона
1. Вырежи 2 рога из `08-dragon-mask.svg`
2. Согни по пунктиру основание
3. Приклей скотчем к каске (строительной или велосипедной)
4. Накидка — вырежи из чёрной/фиолетовой ткани по выкройке
5. Папа надевает каску и накидку → готов Эндер-дракон!

### 🔴 Лавовые блоки
1. Распечатай `04-lava-blocks.svg`
2. Вырежи 12 блоков
3. **Очень желательно заламинировать** — на полу/асфальте быстро порвутся
4. Разложи на земле для паркура

## Сценарий проведения (40 минут)

### 12:00 — Этап 1: Спавн
Дети выходят во двор. На видном месте лежит **сундук** (коробка под дерево).
- Внутри — **Записка №1** (прочитать вслух)
- Задание: найти 3 алмаза

### 12:00–12:10 — Этап 2: Биом «Копай!»
Вдоль бордюров, в песке, под листьями, в горшках спрятаны 3 голубых алмаза.
- Дети ищут, собирают в мешочек

### 12:10–12:12 — Этап 3: Крафт-станция
На столе — картонная сетка 3×3 (`10-craft-grid.svg`).
- Дети кладут 3 алмаза в верхний ряд
- Ведущий проверяет → вручает Алмазный клинок
- **Записка №2** (на обороте)

### 12:12–12:25 — Этап 4: Паркур (obby из Roblox)
Между деревьями натянута верёвочка — перепрыгнуть.
- На земле лавовые блоки (`04-lava-blocks.svg`) — красные, наступать нельзя!
- Номера этажей (`13-obby-floor-signs.svg`) — 5 уровней
- Прошли → получают Пламя выносливости + **Записка №3**

### 12:25–12:30 — Этап 5: Моб-арена
Папа в маске дракона/каске — «Зомби».
- Дети кидают мячики (3 попадания)
- Моб падает (эффектно!), роняет сундук
- Внутри — Слеза моба + **Записка №4**

### 12:30–12:35 — Этап 6: Тайник
- Ищут Первородную пыль в неожиданном месте (почтовый ящик/под крыльцом)
- Находят → **Записка №5**

### 12:35–12:40 — Финал: Портал и Эндер-дракон
- Дети несут все 4 ресурса к фиолетовому порталу (`12-scp-obby-signs.svg`)
- Появляется папа в полной маске дракона — Эндер-дракон!
- Дракон рычит/машет «крыльями» (накидкой)
- Дети «побеждают» → дракон падает
- **Главный сундук** с подарками! 🎉

### 12:40+ — Подарки
- Открывают сундук
- Снимают на видео для RUTUBE

## План Б (на случай погоды)

| Проблема | Решение |
|---|---|
| Дождь | В подъезд/подвал/гараж. Паркур между комнатами, лава = подушки |
| Грязь | Алмазы прятать не на земле, а в крупе/фасоли в контейнере |
| Папа занят | Нарисовать дракона на коробке — дети кидают в лицо |
| Ветрено | Лавовые блоки приклеить скотчем к асфальту |
| Нет времени красить | Алмазы из цветного картона/пластилина |

## Карта прогресса

Распечатай `map/11-progress-map.svg`.
- По ходу квеста дети наклеивают стикеры на собранные ресурсы
- Стикеры — вырезать из нижней части того же листа
- **Заламинировать** — можно писать фломастером и стирать

## Roblox-стиль (для атмосферы)

- Мобов подписать **«SCP»** вместо криперов
- Паркур назвать **obby** с номерами этажей
- Здоровье = **HP bar** (сердечки)
- Портал = **The Void**
- Ресурсы наклеивать на **карту прогресса**
